**GUÍA EXPLICATIVA**

La página está hecha en HTML5 y CSS puro, sin flexbox, sin grid, sin @media y sin JavaScript. El layout se arma con float combinado con clearfix, usando unidades relativas como em y %, y variables en :root para manejar colores y fuentes desde un solo lugar.

Cada section tiene su propio id (inicio, podcast, premisa, causas, etc.), que cumple dos funciones. Por un lado sirve para la navegación interna: un enlace como <a href="#podcast"> salta directo hasta <section id="podcast">. Por otro lado sirve para accesibilidad, ya que cada section usa aria-labelledby="titulo-x" apuntando al id de su propio h2, para que un lector de pantalla anuncie correctamente el título al entrar a esa parte de la página. Un detalle curioso del proyecto es que estos ids no se usan como selectores de CSS, o sea que en ningún lado aparece algo como #podcast {}; todo el estilo se maneja con clases, y el ajuste de scroll al saltar por ancla se resuelve con scroll-margin-top puesto en la clase .seccion en vez de en el id. Un uso más "clásico" de un id en CSS sería simplemente escribir #podcast { scroll-margin-top: 4.5em; }, apuntando solo a esa sección puntual.

Las pseudoclases en cambio sí se usan bastante y sirven para reaccionar a distintos estados de un elemento. Están las de interacción, como a:hover y a:focus, que cambian el color de un enlace cuando el cursor pasa por encima o cuando recibe foco navegando con teclado, patrón que se repite tanto en el menú como en el footer. También están las de posición, como .galeria figure:nth-child(3n), que selecciona cada tercera imagen de la galería para quitarle el margen derecho y que la fila cierre bien, ya que el layout se arma con float y no con grid. Como ejemplo propio, que no está en el código, se podría agregar .galeria img:hover { opacity: 0.8; } para que las fotos bajen un poco su opacidad al pasar el mouse por encima.

La diferencia de fondo entre ambos conceptos es que un id identifica un elemento único, como id="podcast", mientras que una pseudoclase no identifica nada sino que describe un estado o situación del elemento, como :hover indicando que el cursor está encima o :last-child indicando que es el último de la lista.
